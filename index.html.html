Методика

IGR = (GR − GRmin) / (GRmax − GRmin), 0 ≤ IGR ≤ 1
Vsh, Ларионов (древние): 0.33·(22·IGR − 1); Ларионов (третичные): 0.083·(23.7·IGR − 1); линейный: Vsh = IGR
PHID = (ρma − RHOB) / (ρma − ρf)
PHIT = (PHID + NPHI) / 2
PHIE = PHIT − Vsh·PHITsh, PHIE ≥ 0
Sw = ( a·Rw / (PHIEm·RT) )1/n, 0 ≤ Sw ≤ 1
SOIL = 1 − Sw
Керн: PHIEГИС(z) = среднее PHIE на [z + s − h, z + s + h], h = 0.15; Δ = Кпкерн − PHIEГИС; bias = среднее Δ, RMSE = √(среднее Δ²), r — Pearson
Коллектор по отсечкам: VSH ≤ отсечки и PHIE ≥ отсечки. Разрывы до 0.3 м склеиваются, интервалы короче 0.3 м отбрасываются
Нетто нефть: сумма шагов выше ВНК, где Vsh ≤ отсечки, PHIE ≥ отсечки и SOIL ≥ отсечки
  • Значения -999.25 и пропуски не участвуют в расчётах. Там, где PHIE ≤ 0.02, SOIL не считается (на планшете разрыв кривой), это не коллектор.
  • Каверны: при включённой опции точки с CALI больше медианы на 1.5 дюйма исключаются из PHIE и SOIL, так как RHOB и NPHI там искажены.
  • Коэффициенты Ларионова 0.33, 0.083 и 3.7 записаны по памяти, нужно подтвердить по вашей методике.
  • NPHI принят в единицах известняка без поправок за литологию и скважину, ρma = 2.65 для песчаника. Если NPHI в процентах, он делится на 100. Подходит ли это вашему разрезу, нужно подтвердить.
  • Модель Арчи для чистого коллектора по PHIE: в глинистых песках SOIL может быть завышен или занижен. Rw, a, m, n, PHITsh и отсечки здесь условные, нужно подтвердить по керну и воде вашего месторождения.
  • Колонка коллекторов стоит после дорожки SOIL. Левая половина — интервалы по отсечкам ГИС, правая — принятые пласты из таблицы. Кровля, подошва и ВНК правятся числом или кнопками ▲ ▼ с выбранным шагом. Кнопка «Привязать к ГИС» заменяет границы каждого пласта на границы интервалов по отсечкам, которые его пересекают. Заливки PHIE и SOIL рисуются только внутри принятых пластов: выше ВНК зелёные, ниже ВНК синие. Условность параметров склейки и минимальной мощности 0.3 м нужно подтвердить.
  • Образцы керна рисуются на глубине «глубина в файле + сдвиг s». Кнопка «Подобрать сдвиг» ищет s от −2.0 до +2.0 с шагом 0.05 по максимуму Pearson между Кп керна и PHIE. В примере истинный сдвиг известен и показан в блоке сопоставления.
  • Керновая пористость обычно полная, а PHIE эффективная, поэтому в глинах керн заведомо выше PHIE. Для оценки качества сопоставления смотрите строку «В пластах». С чем честнее сравнивать керн, с PHIE или PHIT, нужно подтвердить. Допуск расхождения 0.04 д.ед. условный, нужно подтвердить.
  • DTP принимается из кривых DTP, DT, DTC, DTCO, AC. На расчёты он не влияет, показан для контроля.
Какой LAS ожидается

LAS 2.0, первая кривая — глубина. Нужны GR (для Vsh), RHOB и NPHI (для PHIE), RT (для SOIL), по возможности CALI. Допустимые имена: GR; DTP/DT/DTC; RHOB/RHOZ/DEN; NPHI/TNPH/NPOR; RT/LLD/ILD/RDEP; CALI/CAL. Значение NULL берётся из заголовка и из -999.25.
